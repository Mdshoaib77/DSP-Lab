
# FFT Spectrum Analysis (DSP Lab)

MATLAB code to generate a signal of 50 Hz + 120 Hz sine waves
and analyze its frequency content using FFT.

## Parameters

- Sampling frequency: 1000 Hz
- Duration: 1 s
- Frequencies: 50 Hz (amp 1), 120 Hz (amp 0.5)

## Output

Time-domain plot and single-sided amplitude spectrum.

## How to run

Open `fft_spectrum_analysis.m` in MATLAB/Octave and run.
